# BATIR — نرم‌افزار حسابداری و انبارداری باتیر

پروژه نرم‌افزار حسابداری و انبارداری فروشگاه باتیر.

نسخه اولیه با رابط فارسی، ریال، SQLite و ساختار توسعه برای خرید، فروش، برگشت، مشتری، چک و اتصال WordPress ساخته می‌شود.

Build system verified and refreshed on 2026-10-01.

Build compatibility fix: .NET Framework 4.8 / Windows 7.
